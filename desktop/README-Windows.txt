Zero VPN 1.5.3 — نسخه ویندوز
================================

نصب و اجرا
----------
1. فایل ZIP را در یک پوشه باز کنید (Extract)
2. روی ZeroVPN.exe دوبار کلیک کنید
3. اگر ویندوز پیام SmartScreen داد: روی More info و بعد Run anyway بزنید
   (برنامه امضای دیجیتال پولی ندارد؛ به همین دلیل این پیام طبیعی است)

نحوه استفاده
------------
1. در صفحه سرورها روی «افزودن اشتراک» بزنید و لینک اشتراک خود را وارد کنید
   (یا کانفیگ را در کلیپ‌بورد کپی کنید و «کلیپ‌بورد» را بزنید)
2. سرور مورد نظر را انتخاب کنید
3. دکمه بزرگ وسط صفحه را بزنید — تا وصل شدن، حلقه نئونی دور دکمه می‌چرخد
4. پراکسی سیستم ویندوز به‌صورت خودکار روشن می‌شود و مرورگرها از تونل رد می‌شوند
5. برای قطع، دوباره دکمه را بزنید

نکته‌ها
------
- پروتکل‌های پشتیبانی‌شده: VMess / VLESS / Trojan / Shadowsocks
- پورت‌های محلی: SOCKS 10808 و HTTP 10809 (از تنظیمات قابل تغییر است)
- تمام فایل‌ها Portable هستند؛ برای حذف کامل، فقط پوشه را پاک کنید
- اگر مشکل پیش آمد، فایل xray.log داخل پوشه %APPDATA%\ZeroVPN را بررسی کنید
