# Privacy Policy | سیاست حفظ حریم خصوصی

## English

Zero VPN does not collect, store, or share any personal data. There are no analytics, no tracking, and no advertising SDKs in the app.

- Your server configurations and subscriptions are stored only on your device.
- When you tap "Real ping test", the app connects through the selected server and requests your exit IP info (country/IP) from the configured IP echo service to display it to you.
- On every launch the app queries the public GitHub API to check for a newer app/core release. This request contains no personal data.
- VPN traffic is tunneled exclusively through the server you configure.

## فارسی

Zero VPN هیچ داده شخصی را جمع‌آوری، ذخیره یا به اشتراک نمی‌گذارد. هیچ آنالیتیکس، ردیاب یا SDK تبلیغاتی در برنامه وجود ندارد.

- کانفیگ‌ها و سابسکریپشن‌های شما فقط روی دستگاه خودتان ذخیره می‌شوند.
- هنگام تست پینگ واقعی، برنامه از طریق سرور انتخاب‌شده متصل می‌شود و برای نمایش کشور/IP خروجی، از سرویس IP echo تنظیم‌شده کوئری می‌گیرد.
- در هر بار اجرا، برنامه برای بررسی نسخه جدید، از GitHub API عمومی استفاده می‌کند؛ این درخواست هیچ داده شخصی ندارد.
- ترافیک VPN فقط از سروری عبور می‌کند که خودتان تنظیم کرده‌اید.
